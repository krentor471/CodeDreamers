# Реализация отмены команд в CodeDreamers

## Обзор

Добавлена возможность отмены (undo) для всех команд, доступных в пользовательском интерфейсе.

## Реализованные команды с поддержкой undo

### 1. Создание курса (`CreateCourseCommand`)
- **Выполнение**: Создает курс в БД через CourseFactory
- **Отмена**: Удаляет курс и связанные теги из БД
- **UI**: Форма создания курса использует `/api/command/execute`

### 2. Добавление урока (`AddLessonCommand`)
- **Выполнение**: Добавляет урок в курс
- **Отмена**: Удаляет урок из БД
- **UI**: Автоматически при создании курса с модулями

### 3. Удаление курса (`DeleteCourseCommand`)
- **Выполнение**: Удаляет курс и все зависимости
- **Отмена**: Восстанавливает курс (базовая информация)
- **UI**: Кнопка 🗑️ на карточках курсов (только для admin)

### 4. Изменение состояния курса (`ChangeStateCommand`)
- **Выполнение**: Переводит курс в новое состояние
- **Отмена**: Возвращает предыдущее состояние
- **UI**: Админ-панель, раздел "Состояние курса"

### 5. Отправка уведомлений (`SendNotificationCommand`)
- **Выполнение**: Отправляет уведомление через EventBus
- **Отмена**: Удаляет запись из БД
- **UI**: Админ-панель, раздел "Рассылка уведомлений"

## Интерфейс отмены

### Кнопка отмены
- **Расположение**: Админ-панель → Командный интерфейс
- **Текст**: "⤶ Отменить последнюю команду"
- **API**: `POST /api/command/undo`

### История команд
- Глобальная история `CommandHistory` в `app.py`
- Хранит последние выполненные команды
- Поддерживает `undo_last()` для отмены

## Технические детали

### Command Pattern
```python
class Command(ABC):
    @abstractmethod
    def execute(self) -> str:
        pass
    
    @abstractmethod
    def undo(self) -> str:
        pass
```

### CommandHistory
```python
class CommandHistory:
    def execute(self, command: Command) -> str:
        result = command.execute()
        self._history.append(command)
        return result
    
    def undo_last(self) -> str:
        if not self._history:
            return "Nothing to undo"
        return self._history.pop().undo()
```

## API Endpoints

- `POST /api/command/execute` - Выполнение команды
- `POST /api/command/undo` - Отмена последней команды
- `DELETE /api/courses/<id>` - Удаление курса (через Command)

## Пользовательский опыт

1. **Создание курса**: После создания показывается сообщение "Можно отменить в админ-панели"
2. **Удаление курса**: Подтверждение с напоминанием о возможности отмены
3. **Изменение состояния**: Мгновенная отмена через админ-панель
4. **Уведомления**: Отмена удаляет из истории уведомлений

## Ограничения

- История команд хранится в памяти (сбрасывается при перезапуске)
- Отмена доступна только для последней команды
- Некоторые команды (например, отчеты) имеют "пустую" отмену (read-only операции)
